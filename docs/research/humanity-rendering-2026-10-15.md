## Testing lessons

The new Ekstrom record initially inherited a cohort-wide notice claiming an
earlier email had been removed, despite having no such history. A scoped
contact-disclosure override now suppresses only that fictional notice; older
members retain their documented email cautions. Native desktop/mobile and an
API regression assertion protect the distinction.

The initial broad browser attempts exposed test defects as well as content
gaps: manually created contexts lacked action timeouts; responsive markup
included hidden duplicates; the clipped server initial-HTML fallback could be
mistaken for the hydrated page. Scope checks to `#main-content`, create a fresh
page per route, set context timeouts and keep source/privacy assertions.
Non-interactive photo decoding does not require an action-stability wait on
animated artwork. Initial failed/timed-out attempts are not passing evidence.

Stable citation IDs take precedence over shared URLs in preservation diffs.
A new dated citation must not replace an earlier same-URL citation's notes.
Legacy URL-only citations may acquire an ID without a false removal.
Portrait hold reasons must date from the individual approval where present,
not pretend adding one portrait re-reviewed every older delivery.
