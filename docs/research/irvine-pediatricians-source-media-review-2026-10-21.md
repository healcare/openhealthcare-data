# Irvine pediatricians pilot — source, narrative and portrait review

Reviewed and applied: 2026-10-21. App main revision: 5cf59d678af21328537dfcd94165787f81d036c3.

## Scope and outcome

Seven new stable provider IDs were added to the noindex Irvine pediatricians research pilot. The app inventory after import contains 139 providers across 18 directories, 120 qualifying source-backed humanity narratives, and 131 independently inventoried local portrait deliveries. These are content-completeness counts, not clinical verification, licensure confirmation or completed human review.

Each profile remains source-stated, pending human review and pending independent license lookup; the directory and profiles remain non-indexable. No independent verification date was entered. Keep eligibility, capacity, fees, insurance and referral requirements unknown unless separately supported.

## Profile and media review

The clean contribution JSON contains full claim-mapped narratives, access sections, source identifiers, review controls and image provenance. Each narrative is an original attributed summary of a named official provider profile; no clinical outcome, bedside manner, credential or license verification is inferred.

For each named profile, the associated official page exposed one individually named portrait candidate. Its original bytes were retrieved normally, decoded and visually inspected against the named page; the local preview was resized proportionally without cropping or upscaling. No second distinct named image was found in the reviewed profile, so no gallery photos were assigned. Ambiguous group/team imagery was excluded.

Reuse terms remain unknown. Local files are modest, immediate source-linked previews only; this review makes no ownership, blanket-license, derivative-card or structured-data-image approval claim. Direct image GET responses had no Set-Cookie header; that observation does not establish cookie behavior of the source webpages.
