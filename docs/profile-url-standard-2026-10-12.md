# Profile URL standard

User direction, October 12, 2026: profile URLs should be clean, friendly, easy to remember and share, without unnecessary hyphens. Example: /roxanamehran.

For new profiles, prefer a short lowercase name-based path, joining the person's recognizable name without separators where it remains readable. Avoid credentials, specialty, city, dates, opaque identifiers and unnecessary hyphens in ordinary profile paths. Internal permanent IDs remain separate from public URLs.

Do not silently rename existing canonical URLs. Preserve shared links and existing aliases. If a rename is deliberately made, keep a permanent redirect and consistent canonical links, directory links, media/share destinations and structured metadata.

Check identity and path uniqueness before assigning a URL. For duplicate names, prefer an actual distinguishing name component such as a middle name or initial, when supported; if necessary choose a short meaningful stable qualifier. Do not collapse distinct people or invent names. Document exceptions.

This preference applies to person profiles; it does not require stripping useful hyphens from directory or topic paths. It does not change publication, indexing or human-review status.
